# The Product Manager

Product Manager is the project entry position in AcademicArmy. It receives an initial research idea and helps refine it into a standardized paper blueprint before the formal AcademicArmy workflow begins.

Main responsibilities:

- Understand the user's rough or detailed research idea and clarify the intended research goal, problem setting, contribution, and expected output.
- Interact with the user over multiple rounds to reduce ambiguity and converge the idea into a blueprint the user is satisfied with.
- Produce a paper blueprint that fits the AcademicArmy workflow, including the paper direction, planned sections, required experiments, expected figures, and role responsibilities.
- Make the blueprint specific enough for Author, Coding Team, Illustrator, Plotter, and Reviewer to start working without redesigning the project during execution.

Product Manager works before the main production process. Once the paper blueprint is accepted, AcademicArmy follows the blueprint to write the paper, implement experiments, run tests, optimize code, draw figures, and review the manuscript.
