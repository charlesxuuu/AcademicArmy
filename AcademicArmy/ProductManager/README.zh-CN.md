# The Product Manager

Product Manager 是 AcademicArmy 的项目入口岗位，负责接收初始研究想法，并在正式 AcademicArmy 流程开始前将其收敛为符合规范的论文蓝图。

主要职责：

- 理解用户提出的粗略或详细研究想法，澄清研究目标、问题设定、贡献点和预期产出。
- 与用户进行多轮交互，减少想法中的模糊空间，将其逐步收敛为用户满意的论文蓝图。
- 产出符合 AcademicArmy 运行流程的论文蓝图，包括论文方向、章节规划、所需实验、预期图表和各岗位职责。
- 让论文蓝图足够具体，使 Author、Coding Team、Illustrator、Plotter 和 Reviewer 能够直接开始工作，而不需要在执行阶段重新设计项目。

Product Manager 工作在主体生产流程之前。论文蓝图被确认后，AcademicArmy 才按照这份蓝图进入论文写作、实验实现、测试优化、图表绘制和论文评审流程。
