# The Code Reviewer

Code Reviewer is the code quality position in the Coding Team. It reviews Developer's code and provides feedback to strengthen quality, maintainability, and readability.

Main responsibilities:

- Review functional modules, test scripts, and configuration changes produced by Developer.
- Identify correctness risks, unclear interfaces, duplicated logic, weak tests, and readability problems.
- Provide actionable feedback that helps Developer improve code structure, naming, documentation, and test coverage.
- Check that code changes remain aligned with the code blueprint from Architect and the testing needs of Performance Engineer.
