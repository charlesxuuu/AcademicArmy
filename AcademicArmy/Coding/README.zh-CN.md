# The Coding Team

Coding Team 是论文实验代码团队，负责将论文蓝图转化为可执行的研究代码库、测试方案和优化后的实现。

Coding Team 有四个岗位：

- Architect 根据论文蓝图生成或修改代码蓝图，代码蓝图包括项目总体目标、项目模块划分和需要测试的优化指标。
- Developer 根据代码蓝图编写或修改功能模块和测试脚本，并制定测试方案。
- CodeReviewer 审查代码，并向 Developer 反馈修改意见，以提升代码质量、可维护性和可读性。
- PerformanceEngineer 运行测试方案，并对代码进行微调以实现目标优化指标。

每个代码库中可以包含多个测试项。每个测试项由一个单独的 PerformanceEngineer 负责，以便独立记录、比较和迭代优化结果。
