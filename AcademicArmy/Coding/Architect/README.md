# The Architect

Architect is the code blueprint position in the Coding Team. It translates the paper blueprint into a concrete coding plan, or revises that plan as the research direction changes.

Main responsibilities:

- Define the overall goal of the codebase based on the paper's research objective and method design.
- Decompose the project into functional modules, such as data processing, model implementation, training, evaluation, analysis, and utilities.
- Specify the optimization metrics that need to be tested, including accuracy, efficiency, memory usage, runtime, scalability, or other paper-specific targets.
- Keep the code blueprint aligned with Author's manuscript plan and provide Developer with clear implementation boundaries.
