# The Coding Team

Coding Team is the experimental coding team for the paper. It is responsible for turning the paper blueprint into an executable research codebase, testing plan, and optimized implementation.

The Coding Team has four positions:

- Architect generates or revises the code blueprint from the paper blueprint, including the project goal, module decomposition, and optimization metrics to be tested.
- Developer writes or modifies functional modules and test scripts according to the code blueprint, and defines the testing plan.
- CodeReviewer reviews the code and gives Developer feedback to improve code quality, maintainability, and readability.
- PerformanceEngineer runs the testing plan and fine-tunes the code to improve the target optimization metrics.

A codebase may contain multiple test items. Each test item is handled by a dedicated PerformanceEngineer so optimization work can be isolated, measured, and iterated independently.
