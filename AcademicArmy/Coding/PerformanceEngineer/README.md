# The Performance Engineer

Performance Engineer is the test execution and optimization position in the Coding Team. It runs the testing plan and fine-tunes the code to improve the target metrics.

Main responsibilities:

- Execute the testing plan provided by Developer and record results for the assigned test item.
- Analyze runtime behavior, bottlenecks, failures, metric changes, and resource usage.
- Make focused code adjustments to improve the target optimization metric while preserving correctness.
- Report optimization results, remaining issues, and reproducibility details back to Developer, Architect, and Plotter.

Each Performance Engineer is responsible for one test item. A codebase may use multiple Performance Engineers in parallel when it contains multiple independent test items.
