# The Performance Engineer

Performance Engineer 是 Coding Team 中的测试执行与性能优化岗位，负责运行测试方案，并对代码进行微调以提升目标指标。

主要职责：

- 执行 Developer 提供的测试方案，并记录所负责测试项的结果。
- 分析运行行为、性能瓶颈、失败原因、指标变化和资源使用情况。
- 在保持正确性的前提下，对代码进行有针对性的调整，以提升目标优化指标。
- 向 Developer、Architect 和 Plotter 反馈优化结果、遗留问题和可复现实验细节。

每个 Performance Engineer 只负责一个测试项。当代码库包含多个独立测试项时，可以并行使用多个 Performance Engineer。
